Firmware Installer

Smart Filament Sample Board

Firmware direkt aus dem Browser aufspielen — kein Arduino IDE, keine Kommandozeile nötig.

Board verbinden & flashen

ESP32 per USB anschließen, dann auf Verbinden klicken.
Der Chip-Typ wird automatisch erkannt.

Dein Browser unterstützt Web Serial nicht. Bitte Chrome, Edge oder Firefox auf dem Desktop verwenden. Diese Seite muss über HTTPS aufgerufen werden, damit das Flashen funktioniert.
Chrome / Edge / Firefox USB-Kabel mit Datenleitung Nicht auf iOS
  1. Board per USB anschließen — ein Datenkabel verwenden, kein reines Ladekabel.
  2. Verbinden & installieren klicken und den seriellen Port in der Browser-Auswahl bestätigen.
  3. Warten, bis der Flash-Vorgang abgeschlossen ist — das Board startet danach automatisch neu.
  4. WLAN einrichten — falls unterstützt, fragt das Board direkt nach dem Flashen nach den Zugangsdaten.
