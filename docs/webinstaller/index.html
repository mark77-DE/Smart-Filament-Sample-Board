Firmware Installer

Smart Filament Sample Board

Firmware direkt aus dem Browser aufspielen — kein Arduino IDE, keine Kommandozeile nötig.

Ausgewählt: SSD1306 / SH110X OLED

Board verbinden & flashen

ESP32 per USB anschließen, dann auf Verbinden klicken.
Der Chip-Typ (ESP32 / ESP32-S3) wird automatisch erkannt.

Dein Browser unterstützt Web Serial nicht. Bitte Chrome, Edge oder Firefox auf dem Desktop verwenden. Diese Seite muss über HTTPS aufgerufen werden, damit das Flashen funktioniert.
Chrome / Edge / Firefox USB-Kabel mit Datenleitung Nicht auf iOS
  1. Display-Variante oben auswählen — je nachdem, welches Display auf deinem Board verbaut ist.
  2. Board per USB anschließen — ein Datenkabel verwenden, kein reines Ladekabel.
  3. Verbinden & installieren klicken und den seriellen Port in der Browser-Auswahl bestätigen.
  4. Warten, bis der Flash-Vorgang abgeschlossen ist — das Board startet danach automatisch neu.
